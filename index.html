Terraform Cheatsheets

Terraform crea infraestructura (servidores, redes, bases de datos, contenedores) a partir de archivos de texto, en vez de clics. Estas hojas lo explican desde cero y se pueden practicar en tu PC, sin cuenta de nube, con la Práctica con Docker.

Por dónde empezar

Si nunca usaste Terraform, seguí este orden.

  1. Conceptos: qué es la infraestructura como código, el ciclo init → plan → apply y cómo leer un plan.
  2. Práctica con Docker: instalar Terraform y crear tus primeros recursos en tu PC, con todos los archivos.
  3. Lenguaje HCL y Variables y estado: entender cada parte de los archivos que usaste.
  4. Módulos y proyecto: organizar un proyecto real.
  5. CLI y Problemas comunes: para consultar cuando los necesites.

Trabajo diario

Empezar un proyectoinit, providers, descargar
terraform init
Ordenar y revisar el códigofmt, validate, formato
terraform fmt -recursive
terraform validate
Ver qué va a cambiarplan, preview, diff
terraform plan
Guardar el plan y aplicarloplan -out, apply plan
terraform plan -out=tfplan
terraform apply tfplan
Pasar valores de variables-var, tfvars, entorno
terraform plan -var-file="prod.tfvars"
Recrear un recursoreplace, taint, forzar
terraform apply -replace="<tipo>.<nombre>"
Borrar tododestroy, eliminar, bajar
terraform destroy
Ver los outputsoutput, valores, url
terraform output

Estado y mantenimiento

Listar lo que administrastate list, recursos
terraform state list
Ver un recurso en detallestate show, atributos
terraform state show <tipo>.<nombre>
Traer algo que ya existeimport, adoptar
terraform plan -generate-config-out=generado.tf
Liberar un lock trabadoforce-unlock, state lock
terraform force-unlock <ID>
Aceptar cambios manualesrefresh-only, drift
terraform apply -refresh-only
Actualizar providersupgrade, versiones, lock
terraform init -upgrade
Mover el estado a otro backendmigrate-state, s3, remoto
terraform init -migrate-state
Hacer backup del estadostate pull, copia
terraform state pull > backup.tfstate

Explorar y depurar

Probar una expresiónconsole, funciones
terraform console
Ver logs internosTF_LOG, debug
$env:TF_LOG = "DEBUG"
Ver qué providers usoproviders, versiones
terraform providers
Trabajar en otra carpetachdir, entornos
terraform -chdir=envs/dev plan

Workspaces y secretos

Crear o cambiar de workspaceworkspace, entorno
terraform workspace select -or-create dev
Ver el workspace actualworkspace show
terraform workspace show
Pasar una contraseñaTF_VAR, secreto, sensitive
$env:TF_VAR_<nombre> = "<valor>"
Instalar Terraformwinget, instalar
winget install Hashicorp.Terraform
